The last column lists the positions of *every* ciphertext word that can be active, $\bigcup_{p\in\mathrm{supp}(L_2(\Delta))}\mathrm{supp}(L_3(e_p))$. The position lists are the same for a fault in $z$ and a fault in $x$ because the linear layer acts on every word in the same way; only the roles of the words differ.
