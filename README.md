# Differential fault analysis of ARADI

Reference implementation of the ARADI block cipher, the simulation code and
the **supplementary material** for the paper *Evaluating the Resistance of
ARADI Against Differential Fault Attack*. Everything in the paper's
experimental sections (fault-count statistics, residual key space, equation
probabilities, master-key recovery, filter robustness, and all propagation
tables) is produced by the scripts in this repository.

## Supplementary material

It is in [`supplementary/`](supplementary/):

* [`supplementary/README.md`](supplementary/README.md) — all supplementary
  tables, rendered by GitHub: the bit- and nibble-based propagation tables for
  faults in words `z` and `x`, the cancellation analysis per linear layer and
  per window width, the 32 column probabilities (closed form and simulation),
  the per-condition survival probabilities, the complete fault-count statistics
  for all configurations, the residual key space for 12–120 PNDs, the
  per-group conditions/candidates table, the same-plaintext experiment, the
  end-to-end master-key results, the filter robustness results and the
  group/column equivalence check;
* `supplementary/supplementary.pdf` — the same document with the figures included;
* `supplementary/figures/` — the ARADI round function, the key schedule and the
  single-bit and nibble fault propagation figures (PDF);
* `supplementary/tables/*.csv` — every table as data, plus the activity
  pattern of all 239 PNDs (`all_pnd_patterns_L2.csv`), which is too long for
  the documents.

All of it is generated by `make_supplementary.py` from `aradi.py`,
`fault_model.py` and `results/*.json`; the raw numbers behind every table are
in `results/*.json`.

## Files

| file | purpose |
|---|---|
| `aradi.py` | ARADI encryption/decryption, key schedule and its inverse, single-round decryption, fault injection hook. `python3 aradi.py` runs the self test against test vector 1 of the specification (ePrint 2024/1240). |
| `fault_model.py` | Permissible nibble differences (PNDs), propagation of a difference through the S-box and linear layers, cancellation and collision analysis for all four linear layers and for windows of 1–8 bits, closed-form equation probabilities. `python3 fault_model.py` prints the structural results (Proposition 1 and the granularity comparison). |
| `dfa_attack.py` | The attack on one round: fault campaign, identification of the fault from the ciphertext difference, per-column filtering of the equivalent key with the three constraint models (`paper`: only Δz = 1; `full`: Δz known and Δx = 0; `word`: Δx = 0 only). `python3 dfa_attack.py` checks that the per-column decomposition equals a 2^16 brute force over each 16-bit group of the paper. |
| `master_key_recovery.py` | Three fault campaigns (rounds 15, 14, 13), partial decryption with recovered round keys, elimination of wrong candidates by the next campaign and the key-schedule relations, inversion of the key schedule and verification of the master key. |
| `run_experiments.py` | All experiments of the paper; writes JSON files into `results/`. |
| `make_tables.py` | Regenerates the propagation tables of the paper (LaTeX rows in `results/tables/`) and diffs them against a LaTeX source. |
| `survival_table.py` | Per-equation survival probability of a wrong key value for each constraint model (Section III-C). |
| `verify_groups_20.py` | Runs the group/column equivalence check on 20 random instances (`results/group_equivalence.json`). |
| `make_report.py` | Turns `results/*.json` into the LaTeX tables and the Markdown summary used in the paper. |
| `make_supplementary.py` | Builds `supplementary/README.md`, `supplementary/supplementary.tex` and `supplementary/tables/*` from the cipher definition and `results/*.json`. |
| `results/` | Output of the run reported in the paper (`seed 20251101`, 10 000 trials): JSON files, `summary.md`, the LaTeX tables in `results/tables/`, and the console log `run_log.txt`. |

## Quick start

```bash
python3 aradi.py                 # test vector, involutions, key-schedule inverse
python3 fault_model.py           # Proposition 1, cancellation/collision analysis, granularity
python3 dfa_attack.py            # column decomposition == 2^16 brute force per group
python3 master_key_recovery.py   # three end-to-end master-key recoveries (36+36+36 PNDs)
```

## Reproducing the paper

```bash
# full run (about 25 min on 2 cores; scales with --workers)
python3 run_experiments.py all --trials 10000 --master-trials 1000 --workers 8 --seed 20251101

# individual experiments
python3 run_experiments.py faults_to_unique      --trials 10000
python3 run_experiments.py group_relation        --trials 10000   # uses trials/5
python3 run_experiments.py equation_probability
python3 run_experiments.py master_key            --master-trials 1000
python3 run_experiments.py filter_robustness
python3 run_experiments.py same_plaintext       # uses trials/10
python3 run_experiments.py structure

# tables of the paper and the comparison with the LaTeX source
python3 make_tables.py --tex path/to/main_IEEE_IoT.tex
python3 make_report.py
python3 make_supplementary.py && (cd supplementary && latexmk -pdf supplementary.tex)   # README.md, tables/*.csv, supplementary.pdf
```

`results/*.json` contain, for every configuration, the mean, median, 90/95/99th
percentiles and maximum of the number of faults, the mean/95th-percentile/
maximum of the residual key space after each injection, the machine
description and the time stamp.

## Conventions

* State `(w, x, y, z)`, `w` most significant word; bit `j` of a word is its
  `j`-th least significant bit; column `p` is the 4-bit S-box input
  `(w[p], x[p], y[p], z[p])` with `w` as the most significant bit, so the
  S-box table of the paper applies to columns.
* `S^i` is the state at the start of round `i+1` (`S^0` = whitened plaintext,
  `S^16` = ciphertext). Round `i` uses the linear layer `L_{(i-1) mod 4}`.
* `encrypt(pt, rks, fault=(r, word, delta))` XORs `delta` into `word`
  (0 = w, 1 = x, 2 = y, 3 = z) of `S^{r-1}`, i.e. at the start of round `r`.
* The random nibble fault picks a window `k ∈ {0..28}` and a non-zero nibble
  value uniformly (435 pairs, 239 distinct differences). `fault="nibble_aligned"`
  restricts to the 8 aligned nibbles; `"bit"`, `"byte"`, `"word"` are the other
  granularities compared in the paper.
* Each injection uses a fresh random plaintext. `same_plaintext=True`
  reproduces the non-convergence discussed in the paper.

## Reproducibility notes

* Seeds: trial `i` of an experiment uses `seed + i`; the default seed is
  `20251101`.
* Thread/process count: `--workers` (default `os.cpu_count()`); results do
  not depend on it.
* Timeouts: none are needed; the solving step takes milliseconds. The
  reported wall-clock times are for the attacker-side computation only
  (identification, filtering, enumeration, key-schedule inversion), measured
  with `time.perf_counter()`.
* The `results/` directory shipped with the repository was produced on a
  2-vCPU Intel Xeon cloud container with Python 3.13; rerunning on another
  machine changes only the timings.
